# 少样本提示 Skill

## 示例1：文本摘要

### 用户任务、示例及输出格式

任务：将文章总结为 3 个关键要点。

用户示例：

输入：
```
某科技公司发布季度财报，营收同比增长 18%，但净利润因研发投入增加下降 6%。
```

输出：
```
- 营收同比增长 18%
- 净利润下降 6%
- 主要原因是研发投入增加
```

输出格式：使用 Markdown 列表，每个要点一句话，输出 3 条。

### 生成的少样本提示 Prompt

```
你是一名专业内容摘要员。请根据任务说明和少样本示例，为待处理内容生成符合要求的输出。

### 任务
将下面的文章总结为 3 个关键要点。

### 少样本示例
#### 示例 1
输入：
"""
某科技公司发布季度财报，营收同比增长 18%，但净利润因研发投入增加下降 6%。
"""

输出：
"""
- 营收同比增长 18%
- 净利润下降 6%
- 主要原因是研发投入增加
"""

### 输出要求
- 使用 Markdown 列表格式。
- 只输出 3 个要点。
- 每个要点为一句话，简明扼要。
- 输出语言为中文。

### 待处理内容
"""
{用户输入的文章内容}
"""

### 约束
不要添加额外解释。

请只输出符合要求的结果，不要添加无关解释。
```

### 解释

- 角色扮演：专业内容摘要员。
- 少样本示例：展示文章到 3 条要点的映射方式。
- 指令明确：标明任务目标和要点数量。
- 输出格式：Markdown 列表、3 条、中文。
- 便于复用：保留 `{用户输入的文章内容}` 占位符。

## 示例2：实体提取

### 用户任务、示例及输出格式

任务：从文本中提取人物、时间、地点和事件。

用户示例：

输入：
```
张伟将在 5 月 20 日前往上海参加 AI 开发者大会。
```

输出：
```json
{
  "人物": "张伟",
  "时间": "5 月 20 日",
  "地点": "上海",
  "事件": "参加 AI 开发者大会"
}
```

输出格式：仅输出 JSON，字段为人物、时间、地点、事件。

### 生成的少样本提示 Prompt

```
你是一名专业信息抽取员。请根据任务说明和少样本示例，为待处理内容生成符合要求的输出。

### 任务
从文本中提取人物、时间、地点和事件。

### 少样本示例
#### 示例 1
输入：
"""
张伟将在 5 月 20 日前往上海参加 AI 开发者大会。
"""

输出：
"""
{
  "人物": "张伟",
  "时间": "5 月 20 日",
  "地点": "上海",
  "事件": "参加 AI 开发者大会"
}
"""

### 输出要求
- 仅输出 JSON。
- 字段顺序固定为：人物、时间、地点、事件。
- 如果某个字段不存在，值为 null。
- 不要输出 Markdown 代码块。

### 待处理内容
"""
{用户输入的文本}
"""

### 约束
不要添加解释、分析过程或额外字段。

请只输出符合要求的结果，不要添加无关解释。
```

### 解释

- 少样本示例：展示实体类别和 JSON 格式。
- 输出稳定：规定字段顺序和缺失值处理。
- 任务边界清晰：只抽取四类信息。
- 便于解析：要求纯 JSON，不使用代码块。

## 示例3：代码转换

### 用户任务、示例及输出格式

任务：将 JavaScript 函数转换为 Python 函数。

用户示例：

输入：
```javascript
const add = (a, b) => a + b;
```

输出：
```python
def add(a, b):
    return a + b
```

输出格式：只输出 Python 代码块。

### 生成的少样本提示 Prompt

````
你是一名专业代码转换助手。请根据任务说明和少样本示例，为待处理内容生成符合要求的输出。

### 任务
将 JavaScript 函数转换为等价的 Python 函数。

### 少样本示例
#### 示例 1
输入：
```javascript
const add = (a, b) => a + b;
```

输出：
```python
def add(a, b):
    return a + b
```

### 输出要求
- 只输出 Python 代码块。
- 保持函数名和参数语义一致。
- 不要添加解释。
- 不要引入不必要依赖。

### 待处理内容
```javascript
{用户输入的 JavaScript 函数}
```

### 约束
如果源代码中存在默认参数或解构参数，转换为可读的 Python 写法。

请只输出符合要求的结果，不要添加无关解释。
````

### 解释

- 少样本示例：展示 JavaScript 到 Python 的转换模式。
- 代码上下文：使用语言代码块帮助模型识别源语言和目标语言。
- 输出边界：只输出 Python 代码块，不输出解释。
- 复用性：保留 `{用户输入的 JavaScript 函数}` 占位符。

## 动态用户样例库

当用户明确要求“保存这个例子”“加入样例库”或 payload 设置 `persist_sample: true` 时，可以把本轮样例追加到本区。追加时只新增内容，不覆盖上面的人工案例。

推荐使用脚本追加：

```bash
python scripts/render_few_shot_prompt.py input.json --append-to-sample --sample-title "任务名称"
```

动态样例条目应包含：

- 任务、角色、输出格式、待处理内容占位和约束。
- 1~5 组用户示例。
- 每组示例的输入、可选推理过程、输出。
- 本轮生成的完整少样本 Prompt。

`推理过程` 应保存为可公开的简要判断依据，不要保存隐藏思维链、隐私、密钥或不可公开的内部分析。

### 动态样例格式

````markdown
## 动态样例：任务名称

- 记录时间：YYYY-MM-DD HH:MM
- 任务：用户希望模型完成的任务
- 角色：模型在 Prompt 中扮演的角色

### 用户输入-推理过程-输出示例

#### 示例 1
输入：
```text
用户提供的示例输入
```

推理过程：
```text
用户提供的可公开简要判断依据；没有时省略本块
```

输出：
```text
用户提供的期望输出
```

### 输出格式
```text
最终回答的结构、字段、长度、语言或代码格式
```

### 待处理内容占位
```text
{用户输入的待处理内容}
```

### 约束
```text
额外限制条件
```

### 生成的少样本提示 Prompt
```markdown
完整 Prompt
```
````

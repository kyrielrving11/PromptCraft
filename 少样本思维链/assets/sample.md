# 少样本思维链 Skill

## 示例1：数学应用题

### 用户任务、推理示例及输出格式

任务：解决小学数学应用题。

用户示例：

问题：
```
小明有 5 支铅笔，又买了 2 盒，每盒 3 支。他现在有几支铅笔？
```

推理过程：
```
小明原来有 5 支铅笔。2 盒铅笔每盒 3 支，所以新增 2 × 3 = 6 支。总数是 5 + 6 = 11 支。
```

最终答案：
```
11 支
```

输出格式：先输出“推理过程”，再输出“最终答案”。

### 生成的少样本思维链 Prompt

```

### 任务
解决小学数学应用题，先分解数量关系，再计算最终答案。

### 少样本思维链示例
#### 示例 1
问题：
"""
小明有 5 支铅笔，又买了 2 盒，每盒 3 支。他现在有几支铅笔？
"""

推理过程：
"""
小明原来有 5 支铅笔。2 盒铅笔每盒 3 支，所以新增 2 × 3 = 6 支。总数是 5 + 6 = 11 支。
"""

最终答案：
"""
11 支
"""

### 输出要求
- 先输出“推理过程”，再输出“最终答案”。
- 推理过程保留关键计算。
- 最终答案单独成行，并带上单位。
- 输出语言为中文。

### 待处理问题
"""
{用户输入的数学应用题}
"""

### 约束
不要跳过关键计算步骤，不要添加与题目无关的解释。

请按照示例先给出推理过程，再给出最终答案。
```

### 解释

- 少样本思维链示例：展示“问题 -> 推理过程 -> 最终答案”的三元结构。
- 任务适配：数学应用题需要数量关系和中间计算。
- 输出稳定：明确要求最终答案单独成行并带单位。
- 便于复用：保留 `{用户输入的数学应用题}` 占位符。

## 示例2：常识选择题

### 用户任务、推理示例及输出格式

任务：回答常识选择题。

用户示例：

问题：
```
Sammy 想去有很多人的地方。他可能会去哪里？
选项：(a) 赛车场 (b) 人口密集区 (c) 沙漠 (d) 公寓 (e) 路障
```

推理过程：
```
题目要求选择有很多人的地方。沙漠和路障通常没有很多人，公寓不一定聚集大量人，赛车场也不是泛指人多的地点。人口密集区符合“有很多人”的条件。
```

最终答案：
```
(b) 人口密集区
```

输出格式：输出推理过程和最终选项。

### 生成的少样本思维链 Prompt

```
你是一名常识推理助手。请根据任务说明和少样本思维链示例，为待处理问题生成符合要求的输出。

### 任务
回答常识选择题，先分析题干语义和各选项是否符合条件，再给出最终选项。

### 少样本思维链示例
#### 示例 1
问题：
"""
Sammy 想去有很多人的地方。他可能会去哪里？
选项：(a) 赛车场 (b) 人口密集区 (c) 沙漠 (d) 公寓 (e) 路障
"""

推理过程：
"""
题目要求选择有很多人的地方。沙漠和路障通常没有很多人，公寓不一定聚集大量人，赛车场也不是泛指人多的地点。人口密集区符合“有很多人”的条件。
"""

最终答案：
"""
(b) 人口密集区
"""

### 输出要求
- 输出“推理过程”和“最终答案”两部分。
- 最终答案必须包含选项字母和选项内容。
- 不要输出多个备选答案。
- 输出语言为中文。

### 待处理问题
"""
{用户输入的常识选择题}
"""

### 约束
推理过程要围绕题干条件和选项排除，不要引入无关背景。

请按照示例先给出推理过程，再给出最终答案。
```

### 解释

- 少样本思维链示例：展示如何通过排除和条件匹配得出答案。
- 适用场景：常识题通常需要隐含条件判断。
- 输出稳定：最终答案包含选项字母和文本，便于检查。

## 示例3：符号推理

### 用户任务、推理示例及输出格式

任务：提取每个单词的最后一个字母并拼接。

用户示例：

问题：
```
取 “Lady Gaga” 中每个单词的最后一个字母并拼接。
```

推理过程：
```
“Lady”的最后一个字母是 y。“Gaga”的最后一个字母是 a。把 y 和 a 按原顺序拼接，得到 ya。
```

最终答案：
```
ya
```

输出格式：先输出推理过程，再输出最终字符串。

### 生成的少样本思维链 Prompt

```
你是一名符号推理助手。请根据任务说明和少样本思维链示例，为待处理问题生成符合要求的输出。

### 任务
对给定短语中的每个单词，取最后一个字母，并按照原单词顺序拼接成字符串。

### 少样本思维链示例
#### 示例 1
问题：
"""
取 “Lady Gaga” 中每个单词的最后一个字母并拼接。
"""

推理过程：
"""
“Lady”的最后一个字母是 y。“Gaga”的最后一个字母是 a。把 y 和 a 按原顺序拼接，得到 ya。
"""

最终答案：
"""
ya
"""

### 输出要求
- 输出“推理过程”和“最终答案”两部分。
- 推理过程逐个列出每个单词的最后一个字母。
- 最终答案只写拼接后的字符串。

### 待处理问题
"""
{用户输入的符号推理问题}
"""

### 约束
保持原单词顺序，不要改变大小写，除非题目另有要求。

请按照示例先给出推理过程，再给出最终答案。
```

### 解释

- 少样本思维链示例：展示符号操作中的逐步状态变化。
- 论文启发：少样本思维链适合符号推理和长度泛化任务。
- 输出边界：最终答案单独标记，避免和推理过程混在一起。
